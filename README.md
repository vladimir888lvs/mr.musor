# Mr. Musor — сайт + заявки (waitlist)

Файлы сайта:
- `index.html` — русский, `kk.html` — қазақша, `en.html` — English
- `styles.css`, `app.js` — дизайн, анимация и форма заявки
- `config.js` — **ваши настройки (3 строки)**
- `favicon.svg`, `apple-touch-icon.png`, `og-image.png` (картинка-превью, когда ссылку присылают в WhatsApp)
- `apps-script/Code.gs` — код для Google Таблицы (принимает заявки)

Заявки попадают в Google Таблицу, вам приходит письмо на каждую заявку, клиенту — письмо-подтверждение с номером MM-0001, MM-0002… (позже это номер договора для Kaspi).

---

## Шаг 1. Google Таблица (5 минут)

1. Создайте новую Google Таблицу, назовите «Mr. Musor — заявки».
2. Меню **Расширения → Apps Script**.
3. Удалите всё в файле `Code.gs` и вставьте содержимое `apps-script/Code.gs`. Сохраните (Ctrl+S).
4. Вверху выберите функцию **setup** и нажмите **▶ Выполнить**. Google попросит доступ — разрешите (Advanced → Go to project → Allow). Появятся вкладки «Заявки» и «Сводка по ЖК».

## Шаг 2. Опубликовать как веб-приложение

1. В Apps Script: **Развернуть (Deploy) → Новое развертывание**.
2. Тип: **Веб-приложение**.
   - Выполнять как: **Я (ваш email)**
   - Кто имеет доступ: **Все (Anyone)**
3. Нажмите **Развернуть** и скопируйте ссылку, которая заканчивается на `/exec`.

## Шаг 3. Вставить ссылку в сайт

Откройте `config.js` и заполните:

```js
SCRIPT_URL: 'https://script.google.com/macros/s/………/exec',
WHATSAPP: '77011234567',   // ваш номер, только цифры
INSTAGRAM: 'mrmusor.kz'    // без @, или оставьте пустым
```

Пока `SCRIPT_URL` пустой, форма не отправляет заявки и просит клиента написать в WhatsApp.

## Шаг 4. Домен mrmusor.kz и хостинг

Важно: по правилам зоны .kz сайт на домене .kz должен размещаться на сервере в Казахстане. Поэтому для mrmusor.kz используем казахстанский хостинг (например, PS.kz), а не Netlify.

1. На https://www.ps.kz зарегистрируйте домен **mrmusor.kz** (нужны ваши данные ИИН/БИН и оплата; при регистрации укажите хостинг PS.kz как адрес сервера).
2. Там же закажите самый простой тариф **веб-хостинга** (сайт — это просто файлы, база данных не нужна).
3. В панели хостинга откройте **Файловый менеджер** → папку сайта (обычно `public_html` или `www`) и загрузите туда **все файлы из этой папки** (index.html, kk.html, en.html, styles.css, app.js, config.js, favicon.svg, og-image.png, apple-touch-icon.png). Папку `apps-script` загружать не нужно.
4. Включите бесплатный SSL-сертификат (Let’s Encrypt) — сайты .kz обязаны работать по https.
5. Откройте https://mrmusor.kz на телефоне и на компьютере, отправьте тестовую заявку.

Запасной вариант: домен **mrmusor.com** + бесплатный Netlify (https://app.netlify.com/drop — перетащить папку, потом подключить домен в Domain settings). Но на листовках и визитках уже напечатан mrmusor.kz — если выберете .com, макеты нужно переделать.

Пока домена нет, можно проверить сайт через Netlify Drop по временной ссылке.

## Если поменяли Code.gs

Deploy → **Manage deployments** → карандаш → Version: **New version** → Deploy. Ссылка `/exec` остаётся прежней.

## Полезно

- Ссылки для рекламы: добавляйте метки, например `…/index.html?utm_source=instagram` или `?ref=flyer-esentai` — они сохраняются в колонке UTM.
- Колонка «Статус» в таблице — выпадающий список для вашей работы с заявками.
- Дубли (тот же телефон + квартира в течение 30 минут) не создают новую заявку — клиенту возвращается тот же номер.
- Перед запуском замените в подвале `ИП [НАЗВАНИЕ], БИН/ИИН [НОМЕР]` на реальные данные (в трёх html-файлах).
